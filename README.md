# KIBERone Classroom

Локальная панель для уроков: один компьютер тьютора, класс учеников в одной Wi‑Fi сети.
Синхронизация файлов, удалённые команды, история сохранений, раздача программ.

Готовые установщики лежат в [`dist/`](dist/).

---

## Что поставить на машины

| Кто | Файл | Куда |
|-----|------|------|
| Тьютор | [`dist/KIBERoneTutor.exe`](dist/KIBERoneTutor.exe) | Ноут / ПК тьютора |
| Ученик | [`dist/KIBERoneStudent.exe`](dist/KIBERoneStudent.exe) | Каждый ученический ПК |

На Mac тьютора — сборка через `./build_mac.sh` (только на самом Mac).

---

## Как провести урок (коротко)

1. На своём ПК запусти **KIBERoneTutor**. В журнале появится IP и «автопоиск включён».
2. Если Windows спросит доступ к сети — разреши (нужны порты 8765–8767).
3. На ПК учеников запусти **KIBERoneStudent**, укажи номер ПК, нажми **Подключиться** (или «Найти в сети»).
4. В списке слева появятся online-машины — можно слать ссылки, сообщения, обои, скрипт **ШБ**, синхронизировать сохранения.

Папки учеников на рабочем столе тьютора:

`Рабочий стол\Ученики\ПК-1`, `ПК-2`, …

(не по MAC — сразу по номеру, который задали ученику).

---

## Что умеет

- Автопоиск тьютора в LAN (UDP), без ручного IP в большинстве случаев  
- Синхронизация файлов с интервалом (по умолчанию раз в 5 минут; меняется в настройках)  
- История снимков и откат **всех** файлов к версии  
- Сообщения ученику отдельным окном  
- Скрипты запуска: пресет **ШБ** (Wi‑Fi + сброс прокси) и свои `.bat`  
- Стартовый пак установщиков из папки `deploy/`  
- Обновление Student с машины тьютора (Настройки → Обновления)

Смена номера ПК, история и папка ученика — с **главного экрана** (выбери ПК в списке). В «Настройках» — общие вещи: интервал синка, скрипты, пак, обновления.

---

## Сеть и типовые сбои

- Тьютор и ученики в **одной** сети (тот же Wi‑Fi / Host-Only у VM).  
- После обновления EXE Windows снова может спросить firewall — нужно разрешить.  
- Если автопоиск не сработал — впиши IP тьютора вручную (он в журнале Tutor).  
- Антивирус иногда режет первый запуск onefile-сборки — добавь исключение на папку с exe.

## Сборка из исходников

```bat
build.bat
```

Получится `dist\KIBERoneTutor.exe` и `dist\KIBERoneStudent.exe` (иконка из `assets/logo.png`).

Тесты:

```bat
python -m pytest classroom/tests -q
```

Запуск без exe:

```bat
python -m classroom.run_tutor
python -m classroom.run_student
```

## Структура

```
dist/           готовые exe для раздачи
assets/         логотип и иконка
deploy/         файлы для класса (обои, установщики — крупные сами)
classroom/      код
updates/        пакет Student для встройки в Tutor (собирается build.bat)
```

Крупные установщики (>100 МБ) в репозиторий не кладём — клади локально в `deploy/`.
