# Версионирование проекта

1. **Новая фича = Новая версия**: При добавлении любой новой функциональности (feature) в проект необходимо обязательно повышать номер версии в файле `classroom/shared/constants.py` (переменная `APP_VERSION`).
2. **Семантическое версионирование**: Используйте классический подход (Major.Minor.Patch). При добавлении новых фич повышайте `Minor`, при багфиксах — `Patch`.
3. **Commit & Push**: После успешного внедрения фичи, изменения должны быть закоммичены в git с понятным сообщением и запушены на сервер.
